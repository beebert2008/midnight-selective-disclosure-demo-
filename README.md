# Midnight Selective Disclosure Demo

This repository contains a simple **Zero-Knowledge (ZK) concept demo** inspired by the privacy principles of the **Midnight Network**.

## Overview
The purpose of this demo is to show how **selective disclosure** works in a privacy-first blockchain system.

Instead of revealing private data, the application only reveals a verification result.

## What this demo demonstrates
- Zero-knowledge proof concepts (high-level)
- Privacy-preserving logic
- Selective disclosure of information
- Educational example for beginners

## Example Scenario
A user wants to prove they are eligible (18+) without revealing their actual age.

The system:
- Takes private input
- Verifies a condition
- Reveals only the result

## Relation to Midnight Network
Midnight Network enables confidential smart contracts using zero-knowledge proofs and selective disclosure.

In a real Midnight dApp, this logic would be implemented using the Compact language and executed privately on-chain.
